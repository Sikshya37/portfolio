# Sikshya Neupane Portfolio

Personal portfolio website for Sikshya Neupane, Research & Development Engineer.

The site highlights education, experience, research projects, skills, resume, and contact details. Built with React, TypeScript, Vite, and styled-components.

## Tech Stack

- React 19
- TypeScript
- Vite
- styled-components
- tsParticles
- Formspree

## Getting Started

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Resume

The downloadable resume is served from:

```text
public/Sikshya_Neupane_Resume.pdf
```

## Notes

- This project uses npm and `package-lock.json`.
- Generated build output in `dist/` is ignored.
